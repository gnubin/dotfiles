# Описание
Репозиторий содержит конфигурационные файлы для настроки рабочего окружения и скрипты для автоматичекой установки.

# Настройка рабочего окружения
1. Склонируйте репозиторий dotfiles командой
```bash
git clone https://github.com/gnubin/dotfiles.git
```
2. Сделайте bash скрипты испольняемыми файлами командой
```bash
chmod +x *.sh
```
Автоматическая настройка и установка необходимых зависимостей производится через bash скрипты
## Установка и настрока zsh
для установки и настройки zsh запутите скрип install-zsh.sh командой

```bash
./install.sh
```
